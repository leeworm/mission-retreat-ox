# 잠깐, 커피 한 잔? — 수정빛교회 미션 리트릿 O/X 퀴즈

2026년 10월 17일(토) 12:00–14:00, 수정빛교회 1청 미션 리트릿에서 사용할 휴대폰·태블릿용 O/X 퀴즈입니다.

## 현장 사용법 (참여형 UX)

1. [O/X 퀴즈 열기](https://sujungbit-ox.pages.dev/)를 Safari 또는 Chrome에서 엽니다. 별도 앱 설치가 필요하지 않습니다.
2. 시민이 화면의 **O/X 퀴즈 시작**을 누르면 **3세트 중 한 세트가 자동 선택**됩니다. 각 세트는 **창조와 인간 → 죄와 타락 → 그리스도와 구원** 순서로 3문항을 포함하며 전체는 9문항입니다. 같은 세트가 연속으로 출제되지 않도록 순환합니다.
3. 직접 O 또는 X를 터치하면 선택한 답·정답·해설과 **개역개정 성경 본문(일부 발췌)**, 대한성서공회 원문 링크가 표시됩니다. 복수 근거 구절은 각각 분리됩니다.
4. **다음 질문** 또는 **퀴즈 마치기**를 눌러 시민 스스로 다음 단계로 이동합니다.
5. 3문항 후 **복음 설명을 들을지** 선택할 수 있습니다. 동의한 분에게는 전도사님이 전달한 **창조 → 죄 → 예수 그리스도와 구원 → 복음 → 정리**의 5단계 원고를 표시합니다. 원하지 않으면 감사 화면으로 곧장 이동합니다.
6. 정답이나 복음 설명 청취 여부와 관계없이 커피 쿠폰 1매를 제공합니다.
7. 다음 시민을 위해서는 상단의 **처음으로**를 누르면 됩니다.

진행 기록과 전체 9문항 확인은 상단 작은 설정 아이콘에서 접근합니다. 퀴즈 진행 화면에는 내부 운영 안내가 나타나지 않습니다.

행사 장소는 판교역 광장으로 고정되어 있으며, 장소 선택 단계는 없습니다.

문항 해설은 예장합동의 개혁주의 신앙 전통과 웨스트민스터 신앙표준의 창조·타락·구속 이해에 맞춰 구성했습니다. 문항별 표현은 현장 사용 전에 교육 담당자와 함께 최종 확인하는 것을 권합니다.

## 오프라인 사용

HTTPS 웹주소를 인터넷에 연결된 상태에서 방문하면, 지원 브라우저에서 캐시를 저장하여 이후 오프라인으로 사용할 수 있습니다. 행사 전날 각 기기에서 접속한 뒤 비행기 모드로 실제 테스트해 주세요.

## 기기별 통계

OX 3문항 완료·복음 설명 완료 횟수는 각 기기의 브라우저에만 저장됩니다. 전체 기기 통계는 자동 합산되지 않으며, 이름·연락처·정답 선택 이력은 저장하지 않습니다.
