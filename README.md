# 잠깐, 커피 한 잔? — 수정빛교회 미션 리트릿 O/X 퀴즈

2026년 10월 17일(토) 12:00–14:00, 수정빛교회 1청 미션 리트릿에서 사용할 휴대폰·태블릿용 O/X 퀴즈입니다.

## 현장 사용법

1. [O/X 퀴즈 열기](https://leeworm.github.io/mission-retreat-ox/)를 Safari 또는 Chrome으로 엽니다. 카카오톡 파일 미리보기가 아니라 웹사이트 주소로 접속하세요.
2. O/X 퀴즈 시작을 눌러 각 단계에서 한 문항씩 3문항을 진행합니다. 기존 12문항이 단계별로 무작위 출제됩니다.
3. O 또는 X를 선택하면 정답·해설·성경 근거가 표시됩니다.
4. 3문항 종료 후 복음 설명을 들을지 참여자에게 먼저 묻습니다.
5. 복음 청취 여부나 정답에 관계없이 참여자에게 커피 쿠폰 1매를 드립니다.
6. 다음 참여자 시작을 눌러 반복합니다.

행사 장소는 판교역 광장으로 고정되어 있으며, 장소 선택 단계는 없습니다.

## 오프라인 사용

HTTPS 웹주소를 인터넷에 연결된 상태에서 방문하면, 지원 브라우저에서 캐시를 저장하여 이후 오프라인으로 사용할 수 있습니다. 행사 전날 각 기기에서 접속한 뒤 비행기 모드로 실제 테스트해 주세요.

## 기기별 통계

완료·복음 설명·추가 대화 횟수는 각 기기의 브라우저에만 저장됩니다. 전체 기기 통계는 자동 합산되지 않으며, 이름·연락처·정답 선택 이력은 저장하지 않습니다.
